**Send this entire file to the hired P04 performer only.**

Replace `YYYYMMDD` in filenames with the recording date (year month day, no dashes).

---

## Assigned voice family

**P04 — distinct resonance; textured, rougher, or older-sounding.** Soft/neutral. **No fake rasp**, no smoker caricature, no villain voice.

This is not character work and not a paranormal performance.

---

## Performer-wide recording rules

- Text in quotation marks is an **anchor for the sound only**. **Never speak the example word.**
- Each take: about **100–200 ms** quiet room tone, then the target sound, then about **150–250 ms** quiet tail.
- No dramatic intonation, emotion, spooky delivery, sentence melody, or “answer” cadence.
- Comfortable pitch. Do not force very low or very high pitch.
- Vowels/continuants: steady, not sung.
- Transitions: **one smooth articulatory motion**, not two clearly separated letters.
- Do not whisper words. Do not insert an extra vowel to name a consonant (do not say “ess” for `/s/`).
- Same mic, distance, room, and input gain for the entire session.
- Record true **alternate** takes where marked `+ alt`: a **new performance**, not a louder copy. Record alts after finishing the main sheet.

**Do:** natural register; stable pitch and volume; clean relaxed phonetic sounds; compact non-expressive transitions; short room tone before/after; true alts where requested.

**Do not:** act scared/haunted/sinister; whisper recognizable words; add echo/reverb/distortion; growl, scream, laugh, or cry; use rising/falling sentence intonation; say example anchor words; improvise extra words or phrases; process the audio; record backwards.

## Technical delivery

| Spec | Requirement |
|---|---|
| Sample rate | 48,000 Hz |
| Bit depth | 24-bit |
| Channels | Mono |
| Format | WAV, linear PCM |
| Processing | **None** — no compression, limiter, EQ, noise reduction, de-essing, gate, normalization, or reverb |
| Clipping | None |
| Room | Treated or genuinely quiet; no obvious HVAC, traffic, computer fan, or room echo |
| Mic | Quality XLR or good USB condenser/dynamic; **no phone/laptop mic** |
| Distance | About 15–25 cm (6–10 in), consistent |
| Pop control | Pop filter/windscreen; slight off-axis if needed (especially P/K) |
| Peaks | Ordinary speech-like peaks around **-12 to -6 dBFS**, never clipped |
| Files | **One WAV per take** using the filename list below |
| Room tone | Separate **10-second** `ROOMTONE` file |
| Delivery | Raw WAV only — not MP3 |
