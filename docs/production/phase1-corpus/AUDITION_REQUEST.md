Use after they apply. Do not ask for address, tax IDs, or other personal data at this stage.

Hi — thanks for applying.

This job is **short non-word phonetic sounds only**. No dialogue, no character performance, no words or sentences.

**Before any hire**, please send one **raw, unprocessed** audition from the **same microphone and room** you would use for the full job.

## Exact audition (~10 seconds total)

One file, approximately 10 seconds, containing in this order:

1. About **2 seconds** of room tone (silence in the room)
2. `/ə/` — the unstressed vowel at the start of “about” (do **not** say the word “about”) — hold about **0.8 seconds**
3. `/ʃ/` — continuous “sh” texture only (not the word “shh” as acting) — about **0.6 seconds**
4. One **natural quiet exhale** (no vocal pitch, not a gasp)
5. Remaining **room tone** to fill ~10 seconds

Also:

- 48 kHz / 24-bit / **mono** PCM WAV if you can; otherwise your native raw WAV and note the format
- No processing of any kind
- Do not speak example words, your name, or a slate

## Please answer in text (no extra personal details)

- Microphone model
- Recording environment (e.g. treated booth / quiet bedroom; note HVAC/fans)
- Can you deliver **48 kHz / 24-bit / mono PCM WAV**, unprocessed, one file per take?
- Expected turnaround for ~40 short takes + one 10-second room-tone file
- Do you agree **in principle** to the project rights rider (commercial app embedding and modification; **no AI-training rights; no voice-cloning rights**)?
- Are you **18 or older**?
- Does any **union / collective agreement** apply to this work?

If the room is noisy or echoey, do not audition from that setup — we cannot use it.
