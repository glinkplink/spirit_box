# Audition scorecard

Use one copy per candidate. Assign `P01`–`P04` only after hire. Until then use `CANDIDATE — not hired`.

**Critical defects override everything.** A beautiful voice in a bad room is a reject.

Outcome: **PASS** / **HOLD** / **REJECT**

## Kill factors (any one → REJECT)

Mark **FAIL** if present. Do not “average it out.”

| Kill factor | FAIL? | Notes |
|---|---|---|
| Clipping / digital overs | | |
| Obvious room echo / reverb | | |
| HVAC / fan / traffic in room tone | | |
| Strong electrical hum | | |
| Automatic gain pumping / AGC | | |
| Phone/laptop mic or wildly inconsistent level | | |
| Processed audition (EQ, NR, limiter, reverb, loudness) | | |
| Words, slate, or theatrical/spooky performance | | |
| Wrong sounds (not schwa / not SH / acted gasp) | | |
| Will not accept required app/modification rights | | |
| Wants AI-training or voice-cloning rights, or refuses the exclusion | | |
| Under 18 | | |
| Source chain unclear (not their own voice / reused third-party audio) | | |
| Timbre **too close** to an already selected P01–P04 | | |

**Rule:** REJECT if room echo is obvious even if the voice is excellent.

---

## Decision

- **REJECT** — any kill factor, or unusable timetable/rights.
- **HOLD** — technically usable but family overlap, or missing a text answer (18+, rider, union). Do not hire yet.
- **PASS** — no kill factors; rider in principle; 18+; distinct enough to fill an open family.

Hire only on **PASS**, after mapping four PASSes onto P01–P04 with audible separation.

Do not keep a HOLD “because they were cheap.”
