# DEV / TEST ONLY fixtures

These files exist only so the private audio harness can be built and exercised before the Phase 1 human corpus exists.

They are:

- synthetic, non-speech tones plus noise
- clearly named `DEV_TEST_ONLY_*`
- not a production corpus
- not a substitute for commissioned human recordings

They **cannot** pass the canonical 15–20 minute audio gate.

Do not present them as final source material. Do not ship them as the product voice bank.
