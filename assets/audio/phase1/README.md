# Phase 1 human corpus (not in this PR)

Place accepted Phase 1 assets here for repo-side tracking if desired.

The running harness does **not** automatically copy this folder into the app.

To load the corpus into the harness:

1. Copy `manifest.json` and the WAV files into the iOS app’s `Documents/SpiritBoxPhase1Corpus/` directory, or
2. Copy them into `ios/Phase1/` and rebuild.

See `docs/engineering/AUDIO_HARNESS.md` and `docs/production/AUDIO-CORPUS-ACQUISITION-AND-PRODUCTION-PLAN.md`.

Do not add copyrighted radio, YouTube, podcast, movie, TV, or competitor audio.
