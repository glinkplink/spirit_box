# Audio assets

Only original or explicitly licensed source audio may be added here.

Every production asset must eventually be traceable to a rights ledger.

Do not add radio, YouTube, podcast, movie, TV, or competitor samples.

Phase 1 drop-in notes: [`phase1/README.md`](phase1/README.md). The iOS harness loads `Documents/SpiritBoxPhase1Corpus` or bundled `ios/Phase1/` at runtime. Synthetic DEV fixtures live in `ios/DevFixtures/` and cannot pass the canonical audio gate.
